Getting Started

First Launch

  1. Download and install WULU SuperAgent from the download page
  2. Launch the app - you can start chatting immediately with a local API key (no account needed)
  3. Go to Settings to configure your AI provider (OpenAI, Claude, etc.)

Two Modes of Use

Offline Mode Enter your own API key in Settings. All requests go directly to the AI provider. No account needed.

WULU Cloud Sign up for a WULU account and subscribe to a plan. Use the shared NewAPI backend with quota management.

How Quota Works

  • Each API request consumes tokens (prompt + completion)
  • Tokens are deducted from your quota_remaining after each request
  • When quota reaches 0, requests are blocked until you upgrade or the quota resets
  • Subscribe to a higher plan at any time - your quota updates immediately

WULU Cloud

Sign Up

  1. Go to Settings > WULU Cloud in the app
  2. Click "Register" and create an account
  3. Log in with your credentials
  4. Your Free plan quota is ready immediately

Model Proxy

When WULU Cloud is active, all AI requests are proxied through the WULU backend:

  • Your request goes to ai.005656.xyz/api/v1/chat/completions
  • The backend checks your quota and model access
  • If allowed, the request is forwarded to NewAPI
  • Tokens used are deducted from your quota

Change Password

  1. In the app: Settings > WULU Cloud > Change Password
  2. Or in the admin panel at ai.005656.xyz/admin.html

FAQ

Is my data safe?

WULU SuperAgent processes data locally. When using WULU Cloud, requests pass through our backend but are not stored beyond usage logging.

Can I use my own API key?

Yes. Enter your key in Settings and requests go directly to the provider. No account needed.

What happens when my quota runs out?

You will see an error. Upgrade your plan or wait for the monthly reset.
