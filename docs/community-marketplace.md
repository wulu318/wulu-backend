# 社区技能、连接器与专家套件

用户入口 `/community/`，管理员审核入口 `/community/?review=1`。App 的技能、连接器和专家页面均提供“发布我的作品”入口。

## 发布流程

1. 作者登录同一个伍陆账号，填写名称、简介、版本和许可协议。
2. Skill 上传 ZIP；连接器提交 MCP 配置模板；专家套件上传包含多个技能的 ZIP 并填写技能清单。
3. ZIP 保存到数据库目录旁的 `community-uploads/`，不放到公开静态目录。可使用 `COMMUNITY_UPLOAD_DIR` 指定私有存储目录。
4. 审核员在网页查看配置、文件清单和 SKILL.md，也可下载原始 ZIP 进一步检查。
5. 审核员填写原因并通过后，内容进入现有 `/api/skill-store`、`/api/mcp-store`、`/api/kit-store`。作者不能审核自己的投稿。
6. 作者可提交新版本；旧的上架快照在新版本审核期间继续提供。审核会校验提交修订号，避免批准已经被作者修改的内容。
7. 管理员可以下架；作者可以撤回并下架。停止上架后，原市场下载地址也停止公开访问。审核历史保留。

Skill 发布时会重新打包为稳定的 `community-<作品 ID>/SKILL.md` 目录，写入作者提交的版本号，供桌面端识别安装状态和升级。专家 ZIP 中的每个技能必须有与清单 ID 对应的 `<skill-id>/SKILL.md`。

## 限制与验证

- 上传大小 20 MiB，解压大小 100 MiB，最多 1000 个文件；每账号每小时 10 次上传、累计 200 MiB。
- 拒绝路径穿越、符号链接、加密 ZIP、重复路径、`.env` 和常见私钥文件。
- 连接器禁止提交 `env` 值、鉴权头或真实密钥，只保留配置模板和 `requiredEnvKeys`。
- 自动检查不等于代码安全审计；审核员需要确认脚本行为、依赖、授权范围和许可。
- 服务端不会执行用户上传的脚本，也不会自动安装连接器。
- 备份时同时保存 SQLite 数据库与 `community-uploads/`。升级数据库采用新增表，不删除旧用户、套餐或市场数据。

验证命令：`npm install`，`npm test`。测试覆盖审核权限、修订冲突、公开下载隔离、旧版本保留、三类市场返回格式、ZIP 安全检查、网站登录会话和账号信息字段。
